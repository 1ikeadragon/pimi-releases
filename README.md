# Pimi releases

Pimi releases. Source is private.

## Install

- **Desktop:** download the installer from the [latest release](https://github.com/1ikeadragon/pimi-releases/releases/latest): `Pimi-macOS-arm64.dmg` for Apple silicon, `Pimi-Windows-x64.exe` for Windows x64. Check downloads against `SHA256SUMS.txt`.
- **Website:** [1ikeadragon.github.io/pimi](https://1ikeadragon.github.io/pimi/)

## Android

[Download the signed ARM64 APK](https://github.com/1ikeadragon/pimi-releases/releases/latest/download/Pimi-Android-arm64.apk). Android 10 and newer.
